# The Dog Reviews the Mailman

One funny one-line review a dog gives the mailman, under 200 characters.
`main.ts` writes the review to `/output/entry.txt` and prints it.

## The line

> Review of Mr. Hartono: punctual, smells of paper, runs well. Loses one star for never throwing the ball. I threw it at him once. He left.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later (TypeScript runs as-is).
